Pertanyaan Umum
Apakah core.api gratis?
Ya, sepenuhnya gratis. Tidak perlu API key, tidak ada sistem akun atau pembayaran.
Ada rate limit?
Saat ini tidak ada limit ketat, tapi gunakan secara wajar. Request yang mencurigakan (spam/scan) akan otomatis diabaikan.
Endpoint apa saja yang tersedia?
Media downloader (YouTube, Spotify, Facebook, MediaFire), AI (chat, text-to-image, image editor), tools (screenshot web, image to prompt), search (YouTube, Pinterest, LK21), dan stalk Instagram.
Bahasa pemrograman apa yang didukung?
Semua bahasa yang bisa HTTP request — Node.js, Python, PHP, Go, atau cURL. Semua response format JSON standar.
Bagaimana dengan file yang diupload?
File otomatis terhapus setelah 24 jam. Maksimal ukuran file 50MB per upload.
